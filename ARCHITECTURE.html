aside-ctx

Content-addressed context store for AI conversations

⚡ The Problem Every conversation with an AI agent carries the full text of every tool result ever produced — JSON blobs, terminal dumps, file contents — even from months ago. 71.2% of conversation tokens are stale output nobody looks at twice. The AI spends more time re-reading yesterday's garbage than solving today's problems.

Project structure
aside-ctx/
├── main.go — HTTP server on :9876
├── store.go — SHA-256 flat file store + JSONL index
├── handlers.go — POST /store, GET /resolve/{handle}, GET /stats, GET /health
├── digest.go — Digest generation for tool result content
├── cmd/optimizer/main.go — Watches session logs, stores large blobs
├── cmd/memory-indexer/main.go — Compresses MEMORY.md to index
├── *_test.go — Test suite
└── INTEGRATION.md — Integration spec
API
# Store content (returns SHA-256 handle)
curl -s -X POST http://127.0.0.1:9876/store \
  -d '{"content": "..."}'

# Resolve handle to full content
curl -s http://127.0.0.1:9876/resolve/sha256:abc123...

# Stats
curl -s http://127.0.0.1:9876/stats
